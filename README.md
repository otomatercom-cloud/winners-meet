# Winners Meet (Otomater)

- `otm_winners_meet/` - Odoo 19 module (data, API, seats, WhatsApp). Add this folder (`winners-meet`) to the Odoo addons path, install **Winners Meet**.
- `frontend/` - Next.js app (registration, pass, dashboard, check-in, review, seats, hats). `cp .env.example .env.local`, set `ODOO_URL` / `ODOO_DB`, then `npm install && npm run build && npm start` (HTTPS needed for phone camera).

Details: `otm_winners_meet/README.md` and `frontend/README.md`.
